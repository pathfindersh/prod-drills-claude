# Third-party sources

| Source | Used for | Why not build it ourselves | Changes we made |
|--------|----------|----------------------------|-----------------|
| [kodekloudhub/amazon-elastic-kubernetes-service-course](https://github.com/kodekloudhub/amazon-elastic-kubernetes-service-course) (`eks/`) | Basis of `infra/terraform/`: EKS + unmanaged node group + IAM names/policy that the KodeKloud playground's restricted IAM accepts | Playground only allows exact role/cluster names and denies managed node groups; this code is known to fit. No licence file upstream, so it is credited in comments and adapted, not vendored verbatim. | AL2023 + nodeadm instead of AL2; region is a variable; aws-auth managed in Terraform; AWS-managed policies instead of KodeKloud's custom `eksPolicy` (kept only as an off-by-default fallback; the playground cannot delete it); no EKS addon (EBS CSI via Helm in Phase 2); `upgrade_policy` STANDARD; no generated SSH key; no CloudFormation signal; no instance refresh (3-node cap); IMDSv2 required; gp3 root volume |
| [kodekloudhub/certified-kubernetes-administrator-course](https://github.com/kodekloudhub/certified-kubernetes-administrator-course/tree/master/managed-clusters/eks) | Reference only: console walkthrough that explains the cluster role, node role and `aws-auth` join | n/a (read, not copied) | - |
| hashicorp/aws, hashicorp/kubernetes Terraform providers | Provider plugins | Official providers | - |
| [argo-cd Helm chart](https://argoproj.github.io/argo-helm) 10.18.2 (Argo CD v3.6.2) | GitOps controller, installed by `bootstrap.sh up` then self-managed from Git | Standard, well-maintained GitOps tool; no reason to build one | Slim values: no dex, notifications or ApplicationSet; `server.insecure` for port-forward; small requests/limits |
| [aws-ebs-csi-driver Helm chart](https://kubernetes-sigs.github.io/aws-ebs-csi-driver) 2.68.1 (driver 1.68.1) | EBS volumes for PVCs (Phase 1 removed the EKS addon) | Official AWS driver; the only supported way to provision gp3 | 1 controller replica, small resources, no chart StorageClasses (ours live in `platform/storage`); credentials from node role via IMDS |
| [metrics-server Helm chart](https://kubernetes-sigs.github.io/metrics-server/) 3.14.0 (v0.9.0) | `kubectl top` and the Phase 3 HPA (EKS has no metrics API by default) | Official Kubernetes SIG component | 1 replica, small resources |
| [kube-prometheus-stack Helm chart](https://prometheus-community.github.io/helm-charts) 93.6.1 (operator v0.95.2) | Prometheus, Grafana, Alertmanager | Standard, maintained bundle of operator + CRDs + exporters; writing these by hand is not practical | Slim: default rules, control-plane scrapes, admission webhooks and default dashboards off; Prometheus on emptyDir (lab only); 6h retention; Grafana admin from Secret created by bootstrap.sh; 3 custom rules |
